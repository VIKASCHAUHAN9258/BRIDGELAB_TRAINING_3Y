# Assignment 4 – JavaScript Classes and Objects

Complete solutions for all 9 questions from the supplied assignment.

## Requirements
- Core JavaScript (ES6+), no frameworks.
- Node.js for Questions 1, 3, 6 and 9.
- A modern browser for Questions 2, 4, 5, 7 and 8.

## How to run
### Node.js questions
Open a terminal in this folder and run:
```bash
node Q1_Product_Manager.js
node Q3_Library_Management.js
node Q6_Employee_Management.js
node Q9_Shopping_Cart.js
```

### Browser questions
Open the relevant HTML file in a browser:
- `Q2_Student_Validator.html`
- `Q4_Form_Builder.html`
- `Q5_Movie_Ticket_Booking.html`
- `Q7_Login_Validation.html`
- `Q8_Dynamic_Object_Updater.html`

Each HTML page loads its matching JavaScript file. No server or package installation is required.

## Files
Each question has its own `.js` file. Browser-based questions also include a matching `.html` file to provide the form and DOM elements required by the task.
